# 로그인 ID 랭킹 (1.5.3)

닉네임 입력 없이 **모든 계정을 로그인 ID로 자동 집계**합니다. 사용자의 명시적 요청으로 자동 이름 대신 로그인 ID 공개 정책으로 변경했습니다. 공개 범위는 로그인한 사용자이며 익명 인터넷 조회는 허용하지 않습니다. [운영 배포 기록](RANKING-DEPLOYMENT-STATUS.md).

## 사용 방법

`랭킹` 탭에서 내 기록과 TOP 50을 확인하고 학습 후 새로고침하세요. 로그인할 때 쓰는 ID가 표시됩니다. 별도 입력·선택 참여·참여 취소는 없습니다. 학습 기록이 없는 계정도 0점으로 집계합니다. 공동 1등을 포함한 모든 1등 행에는 색이 천천히 회전하는 크로마 테두리만 적용하며 별도 배지 문구는 없습니다. 화면 이탈·오류·로그아웃 시 애니메이션을 중단합니다.

로그인 ID 공개는 계정 존재를 다른 사용자에게 알려줍니다. 이메일 필드·비밀번호·인증 정보·내부 계정 번호는 반환하지 않지만, 로그인 ID 자체에 개인정보가 들어 있으면 그 문자열은 그대로 공개됩니다. 가입 제한·로그인 실패 제한은 유지합니다. 기존 임의 자동 이름 프로필은 스키마 호환/롤백을 위해 저장소에 남겨 두되 랭킹 조회에는 쓰지 않습니다. 새 계정도 프로필 생성 없이 바로 포함됩니다.

## 집계 기준과 한계

- 현재 서버 콘텐츠에 존재하며 진행 상태가 `Mastered`인 단어·문법·표현을 각각 1개씩 합산합니다. 주간이 아닌 누적 순위입니다.
- 같은 항목 반복 정답은 추가 점수가 없습니다. `Learning`으로 변경하거나 서버 콘텐츠를 삭제하면 점수가 줄 수 있습니다.
- 기기 전용 기본팩 진도·문장 코스·Archive·XP는 제외합니다. 클라이언트 총점을 받지 않습니다.
- 동점은 `1, 1, 3` 방식입니다. 동점 내부는 내부 계정 번호 순으로 정렬합니다. TOP 50 밖의 내 순위도 별도로 제공합니다. 동점이 50번째 경계에 걸려도 목록은 최대 50명입니다.
- 기존 진행 API로 사용자가 학습 상태를 변경할 수 있으므로 부정행위 검증된 성적표가 아닙니다. 상품·상금·공식 실력 비교에 사용하지 마세요.
- 자동 실시간 갱신은 없습니다. 오류 시 가짜 순위로 대체하지 않습니다.

## API와 저장소

`GET /ranking`: Bearer 세션 필수. `generatedAt`, `participantCount`, `entries`, `me`를 반환합니다. `me.participating`은 구버전 계약 호환 필드로 항상 `true`이며 내 ID·순위를 제공합니다. 기존 `nickname` 필드에 실제 로그인 ID를 넣어 전송합니다. 응답은 `Cache-Control: no-store`입니다. PostgreSQL Repeatable Read에서 인원수·목록·본인 순위를 조회하며 DB를 쓰지 않습니다. 새 앱은 기존 20자 닉네임 제한 대신 DB의 ID 길이 한도 100자를 지원하고 ID를 마크업이 아닌 일반 텍스트로 표시합니다. 구버전 앱은 긴 ID를 거절할 수 있으므로 1.5.2를 사용하세요.

`PUT /ranking/me`: 폐기된 구버전 참여/닉네임 변경 엔드포인트입니다. 인증 없으면 401, 인증 후에는 410을 반환하며 변경하지 않습니다. 새 앱은 이 요청을 보내지 않습니다. 전역 요청 제한은 유지합니다.

점수는 별도 XP·누적 점수 테이블 없이 서버 진도로 계산합니다. 앱은 계정 변경·로그아웃·탭 이탈 시 요청을 취소하고 이전 계정의 늦은 응답을 차단합니다.

## 배포 주의

초기 랭킹 마이그레이션 `20261007233315_AddRankingProfiles`는 이미 운영에 적용됐습니다. 로그인 ID 랭킹에는 추가 스키마 변경이 없습니다. Down이나 운영 DB 복원은 일반적인 앱 복구 수단이 아닙니다.

미배포 `AddVerifiedRecoveryEmail` 및 다른 변경은 이번 서버 배포에서 제외합니다. 실제 운영 커밋 `26b494a`에 랭킹만 추가한 별도 배포본을 사용하며 기존 가입·로그인을 유지합니다. **전체 작업 트리를 그대로 배포하거나 `APPLY_MIGRATIONS=true`로 재시작하지 마세요.** 향후 이메일 기능은 기존 랭킹 이력·미적용 이메일 마이그레이션 순서·모델 일치·구버전 호환성을 별도 복원 DB에서 다시 검증해야 합니다. 자동 배포의 이메일 준비 게이트도 유지합니다.

## 검증

2026-10-08 로그인 ID 랭킹 전용 배포본: 격리 PostgreSQL 104개 검사 통과. 전체 계정·0점 계정 포함, 실제 ID 표시, 긴 ID, 동시 읽기 6건, 조회 시 프로필 쓰기 없음, 점수 집계, 동점·TOP 50·내 순위, 콘텐츠 삭제, 계정 삭제·세션 폐기, 캐시 금지 및 구버전 수정 요청 거절을 검증했습니다. 클라이언트 격리 검사 46개도 통과했습니다(긴/점 포함 ID, DB 길이 한도, 1등 크로마 대상 포함). Windows 1.5.2 단일 EXE 빌드도 성공했습니다. 클라이언트 검사는 실제 네트워크·기기 계정 저장소를 사용하지 않습니다.
